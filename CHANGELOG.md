# Changelog

## 1.0.1

First release.

- Connect any number of Gmail, Yahoo, iCloud and IMAP accounts, and search them together. Every result names its account.
- Six tools: `list_accounts`, `search_mail`, `read_message`, `read_attachment`, `create_draft` and `send_draft`.
- Attachments: PDF, Word and Excel as text; scanned PDFs and photos as images; text files and calendar invites as text.
- A local sign-in page to add accounts, with server settings looked up automatically.
- Logins stored in the system keychain. Sending is off per account until allowed, and each send asks for confirmation.
- One-command setup for Claude Desktop, Claude Code and Cursor, plus a Claude Code plugin.
